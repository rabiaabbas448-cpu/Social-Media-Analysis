# Social Media Addiction & Student Behavior Analysis

This project analyzes data from 705 students to understand how social media usage affects sleep, mental health, and academic performance.

## Dataset
Students Social Media Addiction dataset from Kaggle. It includes age, gender, academic level, country, daily usage hours, most used platform, sleep hours, mental health score, and addiction score.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Findings
- Higher social media usage is strongly linked to less sleep (correlation: -0.79).
- Addiction score has a very strong negative relationship with mental health score (-0.95).
- WhatsApp, Snapchat, and TikTok users have the highest average addiction scores.
- About 64% of students say social media affects their academic performance.

## Files
- `social_media_addiction_analysis.ipynb`: the full analysis notebook
- `dataset.csv`: the dataset

## Note
These results show relationships, not proof of cause and effect.
